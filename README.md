# Kards卡牌打印工具

***麻烦点个星标，这可以让仓库被更多人看见，谢谢。***

## 说明

这是一个用来**解析卡组代码并制作适合打印的图片**的软件。

默认生成PNG格式打印大图，也可以自行改为PDF等更加易于打印的格式。

注意打印卡牌质量与纸质、打印机有很大关系。

Windows 10以上用户下载发行版<https://github.com/Wu-Chih-yuan/Kards_Printer-TOOL/releases/tag/v1.1-beta>即可使用。

其他操作系统尚无编译版本，可以使用发行版的资源，加上Python环境来运行；也欢迎各位提供macOS等版本的软件包。

开发过程借助了AI工具。

有任何问题请在仓库页面提交issues。

## 优势

有一些网站也有提供自印模版，本软件针对A4等常用纸张大小进行优化，不需要手动设置分辨率等参数，可以制作诸如5×5一页25张卡牌的无损大图来打印，卡图比例约为5∶7，缩放自如，适合打印。

分为2个软件，功能是解析卡组，将卡牌图片塞到指定文件夹，以及根据文件夹中所有图片制作打印大图。
